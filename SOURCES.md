# Sources and Attributions

External services and tools used:
- Microsoft Azure for hosting, Azure Container Apps, Azure Container Registry, Azure Blob Storage, and Azure Functions.
- Docker, Docker Compose, Kubernetes/Minikube, Flask, Requests, and the Azure Functions Python package.

Images:
- Seeded concert images are stored in the project Azure Blob Storage container and referenced from app/database.py.
- The original seeded concert image source pages are Wikimedia Commons pages.
- The homepage hero background uses an Unsplash image URL in app/static/style.css.
